# Discord 101

你好呀!我是小狗 Huggy 🐕,很期待在这门强化学习(RL)课程中与你一起训练!
虽然我(还)不太会捡棍子,但对 Discord 我还是略知一二的。所以我写了这份指南,帮你快速了解它!

<img src="https://huggingface.co/datasets/huggingface-deep-rl-course/course-images/resolve/main/en/unit0/huggy-logo.jpg" alt="Huggy 标志"/>

Discord 是一个免费的聊天平台。如果你用过 Slack,**它和 Slack 非常相似**。Hugging Face 社区的 Discord 服务器拥有 50000 名成员,你可以<a href="https://discord.gg/ydHrjt3WP5">一键加入</a>。有这么多人类可以一起玩!

刚上手 Discord 可能有点让人不知所措,所以让我带你走一遍流程。

当你[注册加入我们的 Discord 服务器](http://hf.co/join/discord)时,需要选择你感兴趣的主题。一定要**勾选 "Reinforcement Learning"(强化学习)**,这样你才能进入包含所有课程相关频道的强化学习分区。如果想加入更多频道,尽管去加!🚀

然后点击下一步,接下来你就可以**在 `#introduce-yourself` 频道做自我介绍**了。


<img src="https://huggingface.co/datasets/huggingface-deep-rl-course/course-images/resolve/main/en/unit0/discord2.jpg" alt="Discord"/>

这些频道都在强化学习分区里。**别忘了订阅这些频道**——在 `role-assigment` 中点击 🤖 Reinforcement Learning 即可。

- `rl-announcements`:获取**课程的最新信息**。
- `rl-discussions`:在这里可以**交流强化学习、分享信息**。
- `rl-study-group`:在这里可以**提问并与同学交流**。
- `rl-i-made-this`:在这里可以**分享你的项目和模型**。

HF 社区服务器上有一个活跃的社区,成员们对许多领域都感兴趣,你同样可以从他们那里学到东西。这里还有论文讨论、活动以及许多其他内容。

这些内容有用吗?我再分享几个小技巧给你:

- 还有**语音频道**可以使用,不过大多数人更喜欢文字聊天。
- 文字聊天中可以**使用 Markdown 语法**。所以如果要贴代码,就可以用这种格式。可惜的是,链接对这种格式的支持就不太好了。
- 你还可以开线程(thread)!当**对话很长**时,这是个好主意。

希望这些内容对你有帮助!有问题就尽管问!

回头见!

Huggy 🐶

# 深度强化学习简介

<img src="https://huggingface.co/datasets/huggingface-deep-rl-course/course-images/resolve/main/en/unit1/thumbnail.jpg" alt="第一单元缩略图" width="100%">


欢迎来到人工智能领域最令人着迷的主题:**深度强化学习(Deep Reinforcement Learning)**。

深度强化学习(Deep RL)是机器学习的一种类型:智能体通过**执行动作**并**观察结果**,来学习**如何在环境中行动**。

在第一个单元中,**你将学习深度强化学习的基础知识。**


然后,你将使用深度强化学习库 <a href="https://stable-baselines3.readthedocs.io/en/master/"> Stable-Baselines3 </a> **训练你的深度强化学习智能体——一架月球着陆器(Lunar Lander),让它正确地降落在月球上**。


<img src="https://huggingface.co/datasets/huggingface-deep-rl-course/course-images/resolve/main/en/unit1/lunarLander.gif" alt="LunarLander">

最后,你将**把这个训练好的智能体上传到 Hugging Face Hub 🤗——一个免费开放的平台,人们可以在上面分享机器学习模型、数据集和演示。**

在深入实现深度强化学习智能体之前,**掌握这些要素**是必不可少的。本章的目标就是为你打下坚实的基础。


在本单元之后,有一个附加单元,你将**能够训练小狗 Huggy 🐶 学会捡棍子,并和它一起玩耍 🤗**。

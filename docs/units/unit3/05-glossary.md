# 术语表

这是一份由社区创建的术语表。欢迎贡献!

- **表格型方法(Tabular Method):** 指这样一类问题:状态空间和动作空间足够小,要近似的价值函数可以用数组和表格来表示。
**Q-learning** 就是表格型方法的一个例子,因为它用一张表格来表示不同状态-动作对的价值。

- **深度 Q 学习(Deep Q-Learning):** 一种训练神经网络的方法:在给定一个状态时,近似该状态下每个可能动作的不同 **Q 值**。
当观测空间太大、无法应用表格型 Q-Learning 方法时,就用它来解决问题。

- **时间局限(Temporal Limitation)** 是当环境状态由帧表示时出现的一种困难。单帧本身不提供时间信息。
为了获得时间信息,我们需要把若干帧**叠加**在一起。

- **深度 Q 学习的阶段:**
  - **采样(Sampling):** 执行动作,并将观测到的经验元组存储到**回放记忆**中。
  - **训练(Training):** 随机选取若干批元组,神经网络使用梯度下降更新其权重。

- **稳定深度 Q 学习的解决方案:**
  - **经验回放(Experience Replay):** 创建一个回放记忆,保存可以在训练期间重复使用的经验样本。
  这使智能体能够多次从相同的经验中学习。同时,它还能帮助智能体在获得新经验时避免遗忘以往的经验。
  - **从回放缓冲区中随机采样**可以消除观测序列中的相关性,并防止动作价值出现剧烈
  振荡或发散。

  - **固定 Q 目标(Fixed Q-Target):** 为了计算 **Q 目标**,我们需要利用贝尔曼方程估计下一状态的折扣最优 **Q 值**。问题
  在于,计算 **Q 目标**和 **Q 值**使用的是同一组网络权重。这意味着每当我们修改 **Q 值**,**Q 目标**也会随之移动。
  为了避免这个问题,我们使用一个参数固定的独立网络来估计时序差分(TD)目标。目标网络的更新方式是:在特定 **C 步**之后,从
  深度 Q 网络复制参数。

  - **Double DQN(双重 DQN):** 一种处理 **Q 值高估**的方法。该方案使用两个网络来解耦动作选择与目标**价值生成**:
     - **DQN 网络**:为下一状态选择要执行的最佳动作(**Q 值**最高的动作)
     - **目标网络**:计算在下一状态执行该动作的目标 **Q 值**。
这种方法减少了 **Q 值**的高估,有助于更快地训练,并获得更稳定的学习。

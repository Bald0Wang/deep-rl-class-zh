# 附加内容：学习使用 Unity 和 MLAgents 创建你自己的环境

**你可以使用 Unity 和 MLAgents 创建自己的强化学习环境**。使用 Unity 这样的游戏引擎一开始可能让人望而生畏，但按照下面的步骤，你可以平稳顺畅地入门。

## 第 1 步：学会使用 Unity

- 学习 Unity 最好的方式是完成["Create with Code" 课程](https://learn.unity.com/course/create-with-code)：这是一系列面向初学者的视频，**你将用 Unity 制作 5 个小游戏**。

## 第 2 步：通过本教程创建最简单的环境

- 然后，当你学会使用 Unity 之后，就可以[使用这个教程创建你的第一个基础 RL 环境](https://github.com/Unity-Technologies/ml-agents/blob/release_20_docs/docs/Learning-Environment-Create-New.md)。

## 第 3 步：不断迭代，创建出色的环境

- 既然你已经创建了第一个简单的环境，就可以借助 [MLAgents 文档（尤其是 Designing Agents 和 Agent 部分）](https://github.com/Unity-Technologies/ml-agents/blob/release_20_docs/docs/)逐步迭代出更复杂的环境
- 此外，你还可以学习 [Adam Kelly](https://twitter.com/aktwelve) 的这门免费课程["创建一个蜂鸟环境"](https://learn.unity.com/course/ml-agents-hummingbirds)


玩得开心！如果你创建了自定义环境，欢迎分享到 Discord 的 `#rl-i-made-this` 频道。
